## ဘယ်က စပြင်မလဲ {#choose}

**Layers** တွင် ဓာတ်ပုံ၏ Raster Layer ကို ရွေးပါ။ Adjustment က Active Layer ကိုသာ ပြောင်းသည်။ မြင်ရသော Layers အားလုံးကို မပြောင်းပါ။ Layer တစ်ခုလုံး ပြင်ရန် **Select → Select None** အရင်လုပ်ပါ။ တစ်နေရာသာ ပြင်လိုလျှင် Selection ထားပါ။

| ပြင်လိုသောအရာ | စသုံးရန် |
| --- | --- |
| ဓာတ်ပုံ မှောင်လွန်း၊ လင်းလွန်းခြင်း | **Colors → Brightness & Contrast…** |
| Color ပြင်းလွန်း၊ ဖျော့လွန်းခြင်း | **Colors → Hue & Saturation…** |
| ဓာတ်ပုံမှ Color ဖယ်ရန် | **Colors → Desaturate…** |
| အမှောင်ဆုံး၊ အလယ်အလတ်နှင့် အလင်းဆုံး Tone များ သီးခြားပြင်ရန် | **Colors → Levels…** |
| မလိုချင်သော အရောင်တစ်မျိုး လွှမ်းနေမှု လျှော့ရန် | **Colors → Color Balance…** |

မစမ်းပြင်မီ `.lime` Project Save လုပ်ပါ။ **Layer → Duplicate Layer** ဖြင့် မိတ္တူလုပ်ပြီး ထိုမိတ္တူကို ပြင်နိုင်သည်။ မူရင်းက အောက်တွင် ကျန်မည်။

## မှောင်နေသော ဓာတ်ပုံကို ပိုလင်းစေရန် {#brightness}

1. **Colors → Brightness & Contrast…** ဖွင့်ပါ။
2. **Brightness** ကို နည်းနည်းစီ တိုးပါ။ အဓိကအရာနှင့် လင်းနေသော နေရာများကိုပါ ကြည့်ပါ။ များလွန်းလျှင် အသေးစိတ်များ ဖျော့ပျောက်နိုင်သည်။
3. ပုံက အလင်းအမှောင် ကွာခြားမှု နည်းနေလျှင် **Contrast** ကို အနည်းငယ်ပြင်ပါ။ တိုးလျှင် အလင်းနှင့်အမှောင် ပိုကွာပြီး လျှော့လျှင် ပိုနီးစပ်လာသည်။
4. **Before** နှင့် **After** နှိုင်းယှဉ်ပြီး အဆင်ပြေလျှင် **Apply** လုပ်ပါ။ Layer ကို မပြောင်းလိုလျှင် **Cancel** သုံးပါ။

**ရလဒ်:** ဓာတ်ပုံကို ပိုရှင်းစွာမြင်ရပြီး အရေးပါသော အလင်းနှင့်အမှောင်နေရာများတွင် အသေးစိတ် ကျန်သင့်သည်။ မူရင်းတွင် မပါခဲ့သော အသေးစိတ်ကို Adjustment ဖြင့် ပြန်မဖန်တီးနိုင်ပါ။

## Color အပြင်းအပျော့ ပြင်ရန် သို့မဟုတ် Color ဖယ်ရန် {#saturation}

**Colors → Hue & Saturation…** ဖွင့်ပါ။ Color ပြင်းလွန်းလျှင် **Saturation** လျှော့ပါ။ ဖျော့လွန်းလျှင် အနည်းငယ်တိုးပါ။ Color မျိုး မပြောင်းဘဲ အပြင်းအပျော့သာ ပြင်လိုလျှင် **Hue** ကို မပြောင်းပါနှင့်။ Hue က Color မျိုးကို ပြောင်းသည်။

အဖြူအမည်း ဓာတ်ပုံအတွက် **Colors → Desaturate…** ရွေးပြီး Preview နှိုင်းယှဉ်ကာ Apply လုပ်ပါ။ အခြား Layers ၏ Color မပြောင်းပါ။ **Image → Mode → Grayscale** က ရွေးထားသော ဓာတ်ပုံတစ်ခုတည်းမဟုတ်ဘဲ Document ကို ပြောင်းသောကြောင့် မတူပါ။

## Brightness တစ်ခုတည်းဖြင့် မလုံလောက်လျှင် Levels သုံးရန် {#levels}

**Colors → Levels…** ဖွင့်ပြီး Color channels ကို အတူပြင်ရန် **Value** Channel မှ စပါ။ Histogram က Layer ၏ Tone များကို ဘယ်ဘက်ရှိ အမှောင်မှ ညာဘက်ရှိ အလင်းအထိ ဖြန့်ပြထားသည်။

- **Input black / Input white** က မည်သည့် မူရင်း Tone ကို အနက်နှင့် အဖြူဖြစ်စေမည်ကို သတ်မှတ်သည်။ နှစ်ဖက်ကို အတွင်းသို့ ရွှေ့လျှင် ဖျော့နေသောပုံ ပိုထင်ရှားနိုင်သည်။ များလွန်းလျှင် အမှောင် သို့မဟုတ် အလင်းနေရာရှိ အသေးစိတ် ပျောက်နိုင်သည်။
- **Gamma** က အလယ်အလတ် Tone များကို ပြင်သည်။ Preview ကြည့်ပြီး အဓိကအရာကို ပိုလင်း သို့မဟုတ် ပိုမှောင်စေကာ အလင်းဆုံးနှင့် အမှောင်ဆုံးနေရာများကိုလည်း သီးခြားစစ်ပါ။
- **Output black / Output white** က ရလဒ်၏ အမှောင်ဆုံးနှင့် အလင်းဆုံးတန်ဖိုးကို ကန့်သတ်သည်။ စတင်ပြင်ရာတွင် မူလ Default အတိုင်း ထားနိုင်သည်။

နည်းနည်းစီပြင်ပြီး Before/After နှိုင်းယှဉ်ပါ။ Tone တချို့ကို ပိုအသေးစိတ်ပြင်ရန် **Curves…** ရှိသည်။ အခြေခံ Adjustment များနှင့် ရင်းနှီးပြီးမှ သုံးနိုင်သည်။

## ရလဒ်ကို ပြန်ပြင်ရန် {#revise}

Correction ကို ပြန်ဖယ်ရန် **Edit → Undo** သုံးပါ။ Layer တွင် Effect ကို ဆက်သိမ်းထားသေးလျှင် **Layer → Edit Layer Effect…** ဖြင့် Settings ပြန်ဖွင့်နိုင်ပြီး **Remove Layer Effect** ဖြင့် သိမ်းထားသော Source ပြန်ယူနိုင်သည်။ Layer တစ်ခုက Effect တစ်ခုသာ မှတ်ထားသည်။ ပုံဆွဲခြင်း သို့မဟုတ် Geometry ပြောင်းခြင်းက လက်ရှိမြင်ရပုံကို Bake လုပ်သည်။ နောက်မှပြန်ပြင်ရန် အားကိုးမည်ဆိုလျှင် [Color Adjustment နှင့် Effects](../../reference/effects/) ကို အရင်ကြည့်ပါ။

`.lime` မူရင်း Save လုပ်ပြီး မျှဝေရန် ပုံသီးခြား Export လုပ်ပါ။
