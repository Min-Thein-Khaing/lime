## Foreground နှင့် Background {#swatches}

Toolbox အပေါ်ရှိ Swatch နှစ်ခုက Tools အတွက် Color သိမ်းထားသည်။ **Foreground** ကို ပုံဆွဲခြင်း၊ Bucket Fill နှင့် Path/Selection Stroke တွင် သုံးသည်။ **Background** ကို ပုံအသစ်၏ Background color Fill၊ **FG → BG** Gradient စသည့် Options တွင် သုံးသည်။

Background swatch က သိမ်းထားသော Color ဖြစ်သည်။ Layer မဟုတ်ပါ။ ၎င်းကို ပြောင်းရုံဖြင့် Canvas အရောင် မပြောင်းပါ။ Eraser က ထို Swatch ဖြင့် ဆေးခြယ်ခြင်းမဟုတ်ဘဲ Pixel ကို Transparent ဖြစ်အောင် ဖယ်သည်။

## Color ရွေးရန် {#picker}

1. Swatch ကို နှိပ်ပါ၊ သို့မဟုတ် **Colors → Foreground Color…** / **Background Color…** ကို ရွေးပါ။
2. Wheel ပေါ်တွင် Color ရွေးပြီး **Brightness** ပြင်ပါ။ သိထားသော Color နှင့် အတိအကျတူရန် **Hex color** တွင် `76B7FF` ကဲ့သို့ ခြောက်လုံး ရိုက်ပါ။
3. အတည်ပြုရန် **Set Color** နှိပ်ပါ။ **Cancel** က ယခင် Color ကို ထားသည်။

Swatch နှစ်ခု လဲရန် Workspace ပေါ်တွင် **X** နှိပ်ပါ၊ သို့မဟုတ် **Colors → Swap Foreground and Background** သုံးပါ။ **Colors → Default Colors** က Foreground ကို အနက်၊ Background ကို အဖြူ ပြန်ထားသည်။ Recent colors ကို မဖယ်ပါ။

## ပုံမှ Color ယူပြီး ပြန်သုံးရန် {#reuse}

**Eyedropper** (`K`) ရွေးပြီး Canvas အတွင်း နှိပ်ပါ။ မြင်ရသော ပေါင်းစပ်ပုံ၏ Color ကို Foreground swatch သို့ ယူပေးသည်။ ပေါင်းစပ်ပုံကို Sample လုပ်သောကြောင့် ထပ်နေသော Layers က ရလဒ်ကို သက်ရောက်နိုင်သည်။

Color picker ဖွင့်ပြီး **Recent colors** အောက်မှ Color chip ရွေးကာ **Set Color** နှိပ်ပါ။ Lime က Tab များနှင့် Picker များကြား Recent colors 12 ခုအထိ မှတ်ထားသည်။ Text၊ Shadow၊ Outline နှင့် Gradient stop Color များလည်း ပါသည်။ အတည်ပြုသော Color နှင့် Eyedropper မှ ယူသော Color ကို မှတ်သည်။ Picker တွင် Cancel လုပ်ထားသော ပြောင်းလဲမှုကို မမှတ်ပါ။

Swatch နှင့် Recent colors က App ပြန်ဖွင့်လည်း ကျန်ပြီး Personal settings ဖြစ်သည်။ Project History နှင့် သီးခြားဖြစ်သည်။ Recent colors က RGB ကိုသာ မှတ်သည်။ Transparency ကို Gradient stop ၏ Opacity ကဲ့သို့ သက်ဆိုင်ရာ Tool တွင် သီးခြားသတ်မှတ်ပါ။
