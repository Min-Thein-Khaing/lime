## ပုံဖွင့်ပြီး Crop လုပ်ရန် {#steps}

1. **File → Open…** မှ PNG၊ JPEG သို့မဟုတ် WebP ပုံကို ရွေးပါ။ ပုံအလွတ်မှ စလိုလျှင် **File → New Image…** ကို သုံးပါ။
2. Toolbox မှ **Crop** ကို ရွေးပါ။ Canvas ကို Focus ထားစဉ် **C** နှိပ်လည်း ရသည်။
3. ချန်ထားမည့် နေရာပေါ် Box ဆွဲပါ။ Box အတွင်းမှ ဆွဲပြီး ရွှေ့ပါ။ လေးထောင့် Handle မှ ဆွဲပြီး အရွယ်ပြင်ပါ။ အချိုးမကန့်သတ်လိုလျှင် **Free**၊ စတုရန်းအတွက် **1:1** ကို ရွေးပါ။
4. **Image → Apply Crop** ကို ရွေးပါ သို့မဟုတ် Canvas ပေါ်တွင် **Return** နှိပ်ပါ။ Crop အပြင်ဘက်ကို Document မှ ဖယ်မည်။ **Edit → Undo** ဖြင့် ပြန်ယူနိုင်သည်။

**ရလဒ်:** ရွေးထားသော နေရာသာ Canvas ထဲ ကျန်မည်။ မူလ Pixel detail မပြောင်းပါ။ Crop က Document ဘောင်ကို ပြောင်းသည်။ Zoom က Screen ပေါ်တွင် မြင်ရသော အရွယ်ကိုသာ ပြောင်းသည်။

## ပြန်ပြင်နိုင်သော မိတ္တူ Save လုပ်ရန် {#save}

1. **File → Save Project As…** ကို ရွေးပါ။
2. **`.lime`** ဖြင့်ဆုံးသော ဖိုင်အမည်နှင့် ပြန်ရှာရလွယ်သော နေရာကို ရွေးပါ။
3. နောက်ထပ် စမ်းပြင်ခြင်းမလုပ်မီ Save လုပ်ပါ။ `.lime` project က Layers နှင့် Editable content ကို ထိန်းထားသည်။

## မျှဝေရန် Export လုပ်ရန် {#export}

1. **File → Export…** သို့မဟုတ် **Cmd/Ctrl+Shift+E** ကို သုံးပါ။
2. **PNG** ရွေးပြီး ဖိုင်သိမ်းမည့် Dialog သို့ ဆက်သွားပါ။
3. သီးခြား ဖိုင်အမည်ဖြင့် Save လုပ်ပါ။ Export က Layers ပေါင်းထားသော Flattened copy ထုတ်ပေးသည်။ ဖွင့်ထားသော Project ကို မပြောင်းပါ။ မသိမ်းရသေးသော Edit များကိုလည်း Saved ဟု မမှတ်ပါ။

PNG က Transparency ကို ထိန်းထားသည်။ JPEG က Opaque ဓာတ်ပုံအတွက် သင့်တော်သည်။ Transparent ပုံအတွက် Format လမ်းညွှန်ကို အရင်ကြည့်ပါ။

## Command သုံးမရလျှင် {#troubleshooting}

Drag လုပ်နေသော Pointer ကို အရင်လွှတ်ပါ။ Crop၊ Gradient သို့မဟုတ် Transform preview ကို Apply သို့မဟုတ် Cancel လုပ်ပါ။ Numeric field ထဲရှိ **Return** က ထို Field edit ကိုသာ အဆုံးသတ်သည်။ Canvas ပေါ်ရှိ **Return** က Preview ကို Apply လုပ်သည်။ Text ရိုက်နေစဉ် **Escape** က Text ကို Commit လုပ်သည်။ ရိုက်ထားသောစာကို မပယ်ပါ။
